# Smart Grocery List Android App

Smart Grocery List is an Android application built using Java, Android Studio, and SQLite. The app allows users to create grocery lists, view saved lists, manage favorites, and use recipe suggestion features.

## Features
- Create and manage grocery lists
- View saved grocery lists
- Manage favorite items or lists
- Navigate between multiple app screens using Intents
- Store app data locally using SQLite

## Technologies Used
- Java
- Android Studio
- SQLite
- XML layouts
- Android Intents

## Project Purpose
This project was created as part of my Information Systems Technology coursework to demonstrate mobile app development, local database storage, user interface design, and troubleshooting skills.
